# 기준 조항 원문 — 원천·이용 조건

`clause_text_collect.py` 가 만든 조항 단위 정적 데이터(`*.json`)의 출처와 이용 조건입니다.
원문은 자르지 않고 전부 저장합니다. 줄이는 것은 화면에서만 합니다. 수집일은 각 파일의 `source.retrieved` 에 있습니다.

| 파일 | 원천 | 공식 원문 | 이용 조건 | 게재 |
|---|---|---|---|---|
| `cfr21.json` | 21 CFR Part 210·211 | eCFR 공개 API `https://www.ecfr.gov/api/versioner/v1/full/{date}/title-21.xml?part=210·211` | 미국 연방정부 저작물 = 공중 영역(17 U.S.C. §105). eCFR 은 편집본이며 공식 법적 판본(연방관보 CFR)이 아니라는 점을 화면에 밝힙니다. | 전문 |
| `eu_gmp.json` | EudraLex Vol.4 Part I 1~9장 + Annex 1(2022) | `health.ec.europa.eu` 공식 PDF(자료실 `library/eu_gmp.json` 과 같은 주소) | © European Union. 출처를 밝히면 재이용 허용(Commission Decision 2011/833/EU, 위원회 법적 고지). | 전문 |
| `ich.json` | ICH Q7·Q9(R1)·Q10 | `database.ich.org` 공식 PDF | © ICH. 각 지침 표지의 법적 고지: ICH 저작권을 표시하면 사용·복제·배포 허용. 번역·수정본은 그 사실을 표시하고 ICH 가 승인한 것처럼 보이게 하면 안 됩니다 → 국문 번역은 "참고 번역" 표시가 필수입니다. | 전문 |

## 이번 묶음에서 빠진 원천과 이유

- **식약처「의약품 제조 및 품질관리에 관한 규정」별표** — 고시는 저작권법 제7조로 보호받지 않는 저작물이라 게재에는 문제가 없습니다. 막힌 것은 수집 경로입니다. 국가법령정보센터 Open API 는 기관 OC 키 등록이 필요하고, 웹 화면은 스크립트로 본문을 그립니다. 별표는 HWP·PDF 첨부입니다. 다음 묶음에서 공식 첨부를 받아 처리합니다.
- **21 CFR Part 600 등 나머지** — 다음 묶음입니다.

## 파서의 한계(PDF)

- PDF 의 표(예: ICH Q7 표 1, Annex 1 청정도 표)는 칸 순서가 섞인 글자로 남습니다. 문장은 그대로이고, 화면에는 공식 PDF 링크를 같이 둡니다.
- 소제목만 있고 본문이 없는 번호(예: ICH Q7 `2.1 Principles`)는 빈 조항으로 남겨 목차에만 씁니다.
- 위첨자 각주 번호는 `[1]`, 쪽 아래 각주 문장은 조항의 `notes` 로 보존합니다.
- 표지·목차·문서 지도는 버리지 않고 문서의 `front_matter` 로 둡니다.

## 번역

`translation_queue.json` 이 국문 번역 대기 목록입니다(조항 id·글자 수·원문 해시). 번역은 구독 경로(Codex 배치)로 나중에 합니다. 원문 해시가 바뀐 조항은 다시 번역합니다.
