# 구독 가입 페이지 기록 — Brevo 속성 만들기 (약 5분, 결재 #2 B안)

구독자가 **어느 페이지에서 구독했는지**를 Brevo 연락처에 남기는 기능의 운영 순서다. 코드는 이미 들어가 있고
**기본 꺼짐**이다. 아래 1~3을 끝낸 뒤 4에서 켠다. 순서를 지키면 가입이 깨질 일이 없다.

## 무엇이 기록되나

| Brevo 속성 | 타입 | 값 예 | 설명 |
|---|---|---|---|
| `SIGNUP_PATH` | 텍스트 | `/glossary/capa/` | 구독 버튼을 누른 페이지 경로. 쿼리·해시 없음, 80자 이내 |
| `SIGNUP_LANG` | 텍스트 | `ko` 또는 `en` | 구독한 사이트 언어 |

가입 시각은 Brevo 기본 항목(연락처 생성일)이 있어 속성을 만들지 않는다. 기존 `SOURCE`·`CONSENT_AT`·`CONSENT_VER`
(회원 가입 경로가 쓰는 속성)는 건드리지 않는다.

## 1. 속성 만들기 (Brevo 화면)

1. Brevo 로그인 → 왼쪽 메뉴 **Contacts**(연락처) → 위쪽 **Settings**(설정) → **Contact attributes**(연락처 속성).
2. **Add a new attribute**(새 속성 추가).
3. 이름 `SIGNUP_PATH`, 타입 **Text**(텍스트), 카테고리 **Normal** → 저장.
4. 같은 방법으로 `SIGNUP_LANG`, 타입 **Text** → 저장.

이름은 **대문자 그대로** 입력한다(폼 필드 이름과 같아야 값이 들어간다).

## 2. 구독 폼에 두 칸 연결하기 (Brevo 화면)

사이트 폼은 Brevo 가 호스팅하는 폼(한국어용·영문용 각 1개)으로 보낸다. Brevo 폼은 **폼에 등록된 필드만** 연락처에
저장하는 것으로 알려져 있어, 두 폼 모두에 같은 작업이 필요하다.

1. **Contacts → Forms**(양식)에서 한국어 구독 폼을 연다 → **Edit**.
2. 필드 추가에서 `SIGNUP_PATH`, `SIGNUP_LANG` 를 추가한다. 보이지 않는 칸(hidden)으로 둘 수 있으면 숨김으로 둔다.
   숨김 옵션이 없으면 사이트가 값을 채워 보내므로 화면에는 나오지 않는다(호스팅 폼 페이지만 직접 열 때 보임).
3. 저장·게시. 영문 폼도 똑같이 한다.

> 이 단계는 Brevo 화면이 바뀌어 있을 수 있어 **실제 저장 여부를 4번의 시험으로 확인**한다. 필드 추가 방법이 없다면
> 대안(속성 값을 API 로 쓰는 중계)을 개발팀이 제안한다 — 그 경우 이 문서를 고친다.

## 3. (선택) API 로 속성 만들기

화면 대신 API 로 만들 수도 있다 — `POST https://api.brevo.com/v3/contacts/attributes/normal/SIGNUP_PATH`,
본문 `{"type":"text"}` (이미 있으면 400 이므로 멱등하게 처리). Brevo API 키는 저장소 GitHub 에는 없고
Supabase 함수 비밀값 `BREVO_API_KEY`(회원 뉴스레터 함수 `newsletter-optin` 이 사용)에만 있다. 1회용이라
화면으로 만드는 편이 빠르다.

## 4. 켜기와 확인

1. GitHub 저장소 → Settings → Secrets and variables → Actions → **Variables** 에서
   `GRM_SIGNUP_PATH_FIELDS` = `1` 을 추가한다. 다음 사이트 배포부터 폼에 두 칸이 실린다.
   (끄려면 값을 지우거나 `0`. 지우면 폼은 종전 그대로로 돌아간다.)
2. 배포 후 **본인 시험용 이메일 1개**로 사이트 아무 페이지(예: 용어사전 한 항목)에서 구독한다.
3. Brevo → Contacts 에서 그 이메일을 열어 `SIGNUP_PATH` = 방금 구독한 페이지 경로, `SIGNUP_LANG` = `ko` 인지 본다.
4. 확인 메일의 구독 확인 버튼이 이전처럼 동작하는지(용어집 PDF 도착 페이지) 본다.
5. 영문 페이지(`/en/...`)에서도 한 번 반복한다.
6. 값이 비어 있으면: 2번(폼 필드 연결)이 빠졌을 가능성이 크다. 가입 자체가 막힌 경우에는 즉시 `GRM_SIGNUP_PATH_FIELDS` 를 지운다.

## 개인정보 처리방침 관련

처리방침(시행 2026-11-03)은 뉴스레터 항목에 "구독 경로"를 이미 적고 있으나, Brevo 이전 항목은 "이메일, 구독 동의 시각"뿐이다.
문구 정리는 대표 결정 사항이다(PR 본문 참조). **켜기(4번) 전에 결정**하는 것을 권한다.
