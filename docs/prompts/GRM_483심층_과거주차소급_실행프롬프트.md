`#453`("심층분석 fan-out 입력이 handoff 에 실리지 않던 2중 단절 수리", 2026-07-27) **이전**

매주 "심층분석 대상 0건"으로 판단했다. 같은 주차에 3·5·4장은 심층분석이 있는데 그건 사람이
손으로 백필한 것이다.

★**원문은 그 주차 deep 델타에 남아 있다** — `source_text` 중앙값 11~12K자로 파싱된 관찰
합계(2~3K)의 3.3~4.1배인 **원본 483 PDF 본문 전체**다.

|---|---|---|

| 2026-07-20 | 33장 | 468,225자 |

## 절차

### 1단계 — 작업목록 생성 (로컬, 주차별 1회)

```
python backfill_deep_483_past_weeks.py build-jobs \
    --brief web/data/briefs/brief_web_2026_07_20.json \
    --deep  web/data/deltas/deep_2026_07_20.json \
    --out   <저장소 밖 경로>/jobs_2026_07_20.json
```

산출은 운영 `deep_analysis_fanout.Job` 과 **같은 계약**이다 —
`[{document_id, body_full, card_type: "fda-483"}]`.

★**jobs 파일은 저장소 밖에 쓴다**(도구가 강제한다). `body_full` 은 이미 델타에 있고, 같은
원문을 두 번 커밋하면 그게 곧 표류 원천이다.

### 2단계 — 생성 (클라우드 fan-out)

- 오케스트레이션 절차: `docs/prompts/GRM_DeepWL_fanout_실행프롬프트.md`
- 생성 프롬프트: **`docs/prompts/GRM_Prompt_DeepFda483_v1.md`** (69장 전건 `card_type=fda-483`
  이므로 유형 분기 없음)
- 카드 1건 = 서브에이전트 1건. **다른 카드 원문을 컨텍스트에 섞지 않는다**(교차오염 방지).

산출 = `responses.json`, 형태는 `{document_id: {4섹션 + observations_ko}}`.

★**원문을 옮겨 적지 마라.** `body_full` 은 jobs 파일에 있다 — 읽고 분석하되 응답에 원문을
복사해 넣는 필드는 `key_violations[].original`(해당 위반의 근거 발췌) 하나뿐이다. 전사
계약은 "짧으면 맞고 길면 흘린다"가 이미 실측된 실패 방식이다.

★**`original` 은 결함 문장에서 끊지 마라.** 483 원문은 `<결함 진술>` 다음에 `Specifically, …`
상세가 붙는 구조다. 결함 문장까지만 발췌하면 국문(`observation`)만 구체적이고 원문은 짧아
병기쌍이 깨진다 → 게이트 `D5-483-ORIGINAL-TRUNCATED` 가 **하드 FAIL** 로 막는다.
(2026-08-25 부터 운영 경로가 이 절단을 원문에서 결정론 복원하지만, 경계를 확정 못 하면
수리하지 않고 그대로 FAIL 시킨다 — 수리에 기대지 말고 처음부터 상세까지 포함하라.)

### 3단계 — 병합 (로컬, 주차별 1회)

```
python backfill_deep_483_past_weeks.py merge \
    --brief web/data/briefs/brief_web_2026_07_20.json \
    --deep  web/data/deltas/deep_2026_07_20.json \
    --responses <경로>/responses_2026_07_20.json \
    --record web/data/deltas/deep_backfill_2026_07_20.json \
    --apply
```

이 명령이 하는 일:
1. 대상 카드에 `deep_analysis` **placeholder 삽입** — 이 69장은 스캐폴드 시점에 fan-out
   대상이 아니어서 키 자체가 없다. `inject_slots` 는 키 없는 카드를 "대상 아님"으로 건너뛴다.
   (새 사실을 만드는 게 아니라 **#453 이 못 세운 표지를 뒤늦게 세우는 것**이고, 대상은
   "그 주차 델타에 원문이 실재하는 483 카드"로 좁혀져 있다.)
2. **운영 병합 경로**(`inject_slots.inject_deep_analysis`) 호출 — 게이트 D1~D5 와 D5b 결정론
   수리가 운영과 동일하게 돈다.
3. 게이트를 못 넘긴 카드는 **싣지 않고**, 삽입했던 표지도 회수한다(빈 키를 남기지 않는다).

`--apply` 없이는 dry-run 이다. `--record` 는 병합에 쓴 델타를 근거로 남긴다(권장).

### 4단계 — 검증

```
python -m unittest discover -s tests
python -m unittest discover -s web/tests
```

그 주차 브리프가 웹 골든이면 재동결이 필요하다(`web/tests/test_render.py --freeze`) —
재동결 diff 가 **해당 카드의 심층분석 블록 추가분에만** 국한되는지 반드시 diff 로 확인하라.
