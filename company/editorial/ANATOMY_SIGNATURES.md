## 2. GRM 시그니처 4개 — 데이터와 검증으로만 가능한 것

1. **세 겹 표시 (서한 원문 / GRM 해설 / 서한에 없음).** 모든 장 머리에 범례. 검정 = 서한 문장 그대로, 크림 = 우리가 푼 말, 노랑 = 서한이 적지 않은 것.
   *남이 못 따라 하는 이유*: 원문 근거를 기계가 검증하는 구조(`validate_v2`)가 있어야 지킬 수 있다.
2. **원문 대조 코너.** 영어 원문과 우리 번역을 나란히 세 문장. 코드가 두 문장이 원천에 그대로 있는지 검사한다.
3. **DB로 본 자리 코너.** 지적사항 DB(문서 3,547건)에서 코드가 직접 센 숫자: 환경모니터링 분류 비중(경고서한 8.1%·483 4.6%·식약처 8.8%·캐나다 0.4%), ISO 5급 언급 경고서한 60/431, PET 규정 인용 다른 서한 1건, 다른 사업장 483이 인용한 자체 SOP. LLM이 쓰지 않는다(`db_position`).
4. **점 그림.** 서한의 "약 75건 중 2건"을 점 75개로. 막대는 크기를 보이고 점은 분모를 보인다. 분모·분자는 근거 문장 안의 숫자여야 통과한다.
- 덧붙임: 카드에 쓴 용어를 용어사전 페이지(`/glossary/<id>/`)로 잇는 띠. 사전에 없는 id는 막힌다.

### 다음 후보 (이번 시범엔 해당 데이터가 없어 넣지 않음)
- **483 → 서한 추적선.** 같은 업체의 483 발행일 → 서한 발행일을 선으로. DB에 두 문서를 모두 가진 업체가 73곳. 이번 사건 업체는 DB에 483이 없어 그리지 못했다.
- **실사 등급 분모.** 같은 사업장 실사 중 지적이 몇 번째인지(기존 `grm-fda-inspection-denominator` 자산).
- **국가 간 같은 주제 한 줄** — 3번 코너에 이미 기관별 비중으로 일부 들어갔다.

## 4. 확인 못 한 것 · 대표 결정
- "서한은 사내 이유·배치 수를 적지 않았다"는 카드 요약 기준이다(`[검증필요]`, 6장에 표시됨). 게시 전 서한 전문과 대조해야 하고, 대조 뒤 `[검증필요]`를 지운다.
- DB의 "ISO 5급 언급"은 영어 원문에서 `ISO 5·Grade A·Class 100` 문자열을 센 값이다(식약처는 영어 원문이 없어 제외). "분리균 미동정을 지적한 다른 서한"은 정규식이 너무 느슨해 세지 못했다 — 그래서 카드에 넣지 않았다.
- DB는 수집분 기준이다("FDA 전체 서한 431건"이 아니다). 카드에는 "우리 DB" 표기와 기준일이 들어간다. 이번 서한은 아직 DB에 없다.
- 점 그림은 "약 75건"이라는 서한 표현을 75개로 그린다 — 정확한 75가 아니다. 카드 문장에 "약"을 남겼다.
- 대표 결정: ① 3장(DB로 본 자리)을 매 건 넣을 수 있는지(PET처럼 비교 대상이 적은 주제는 비교가 얇다) ② 질문·해시태그를 없앤 본문 ③ 코너 이름 8개 확정.
