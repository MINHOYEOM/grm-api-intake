# 지식그래프 3단계 후보 — 난이도·예상 연결률 (2026-11-05, 읽기 전용 실측 + 추정)

원칙: 정확성 최우선 · 틀린 연결 금지 · 연결마다 confidence · DB 적용은 별도 리뷰.

| 후보 | 방법 | 예상 연결률 | 난이도 | 위험·메모 |
|---|---|---|---|---|
| A. 483 ↔ FDA 실사 판정 (FEI 경유) | `findings.fei`(101) × `fda_inspections.fei_number`. 신뢰도: FEI+종료일 일치 0.95 / FEI+30일 이내 0.85 / FEI만 0.6 | 2019-10 이후 483 1,016건 중 **FEI 일치 663(65%), 종료일까지 486(48%)**. 2019-10 이전은 판정 DB 자체가 없어 0 | 낮음(SQL 조인 테이블 1개) | 불일치 353건 사유 미확인(수집 범위: 약품 대상만? 외국 사이트 누락?) — 먼저 `collect_fda_inspections.py` 범위 확인. FEI만 일치는 0.6 이하로 두고 판정 표시는 0.85 이상만 |
| B. 483 ↔ 경고서한 | 경고서한에 FEI가 없어 업체 별칭 키(`firm_alias` 105 포함)로만 가능. 신뢰도 이름 일치 0.7 | 현재 483 업체 1,238 중 109(9%). 별칭·정규화 보강으로 **+1~2%p 수준**(정규화 규칙 변경 실측 +2곳). 천장은 데이터 모집단(경고서한 2021~, 483 2024 쏠림) | 중간 | 이름만으로 잇는 건 동명 이업체 위험 → 483의 FEI가 가리키는 사이트 주소·국가를 경고서한 본문 주소와 대조하는 2차 검증 필요. 대량 연결률 상승은 기대하지 말 것 |
| C. 제품군(무균/비무균 등) 지적 단위 채우기 | 483 원본 `establishment_type`을 규칙으로 `findings.product_family` 에 옮김. 식약처는 제형, 경고서한은 본문 분류 | 483: 문서 2,338 중 **98%가 값 보유**(비어 있음 51). 무균 계열 유형(Sterile·Outsourcing·Sterile+Non Sterile)이 **문서 44%·지적 52%**. 483 지적 12,645행(공개 대상 전체의 약 40%) 즉시 채움 가능. 경고서한(~3,250)·HC(9,732)는 별도 | 483 낮음 / 식약처 중간 / 경고서한·HC 높음(분류 필요) | 'Manufacturer' 같은 모호 유형은 제품군을 단정하지 않고 비움(confidence 낮게). 카드 단계 modality 판정과 값이 어긋나지 않게 같은 어휘 사용 |

권장 순서: A(낮은 난이도·즉시 효과, 수집 범위 확인 선행) → C의 483 부분(즉시 52% 지적에 무균 질의 가능) → B는 A의 사이트 주소 검증이 갖춰진 뒤.
